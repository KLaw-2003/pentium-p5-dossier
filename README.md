# Pentium P5 Processor Dossier

Single-page course dossier for UVA Computer Architecture (Fall 2026).

## Publish with GitHub Pages

1. Create a GitHub repository, e.g. `pentium-p5-dossier`.
2. Upload everything in this directory to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site will be available at `https://<username>.github.io/pentium-p5-dossier/`.

The Google Slides link is already embedded in `index.html`.
